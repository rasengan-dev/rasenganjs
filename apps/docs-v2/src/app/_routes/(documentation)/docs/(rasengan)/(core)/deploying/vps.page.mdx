# Deploying with Node, Bun

Rasengan.js is a framework for building web applications using React. It is designed to be used with Node.js or Bun.

<br />
In this guide, you will learn how to deploy a Rasengan.js app to a Node or Bun server.

## Deploy

To deploy your Rasengan.js app to a Node.js or Bun server, you need to configure your project to use the `@rasenganjs/serve` adapter.
Have a look at the <Link to="/packages/serve">`Serve adapter documentation`</Link> for more information.
