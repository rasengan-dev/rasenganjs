# Rasengan.js Packages

Rasengan.js is a powerful and flexible React framework designed to enhance developer productivity. It is composed of multiple packages that provide essential functionalities for building modern web applications. Below is a list of all Rasengan.js packages and their purposes.

## Core Packages

### rasengan

- **Description**: The core framework package that provides essential functionalities such as routing, layout management, and component composition.
- **Installation**:
  ```bash title="Terminal"
  npm install rasengan
  ```

### create-rasengan

- **Description**: A CLI tool to scaffold new Rasengan.js projects: frontend, [Futon](/docs/futon/getting-started/introduction), [Rasengan Server](/docs/server/getting-started/introduction), or a full-stack monorepo.
- **Installation**:
  ```bash title="Terminal"
  npx create-rasengan@latest
  ```

## Utility Packages

### @rasenganjs/theme

- **Description**: Provides theme management features, including light and dark mode switching.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/theme
  ```

### @rasenganjs/image

- **Description**: An optimized image component with lazy loading and animated previews.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/image
  ```

### @rasenganjs/mdx

- **Description**: Enables MDX (Markdown with JSX) support in Rasengan.js projects.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/mdx
  ```

### @rasenganjs/kurama

- **Description**: A global state management solution built for Rasengan.js.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/kurama
  ```

### @rasenganjs/kage-demo

- **Description**: A lightweight, framework-native library that allows you to create guided step-by-step demos, onboarding flows, and product tours inside your Rasengan.js application.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/kage-demo
  ```

### @rasenganjs/i18n

- **Description**: Adds internationalization (i18n) to your Rasengan.js applications, managing translations via static JSON files.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/i18n
  ```

### @rasenganjs/io

- **Description**: Real-time communication for Rasengan.js applications, built on Socket.IO with a typed React API.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/io socket.io-client
  ```

## Backend Packages

### @rasenganjs/futon

- **Description**: A WinterCG-compatible HTTP engine: router, middleware pipeline, and request/response utilities. See the dedicated [Futon docs](/docs/futon/getting-started/introduction).
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/futon @rasenganjs/runtime
  ```

### @rasenganjs/server

- **Description**: A backend framework built on Futon: controllers, modules, dependency injection, and validation. See the dedicated [Rasengan Server docs](/docs/server/getting-started/introduction).
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/server zod
  ```

### @rasenganjs/ws

- **Description**: NestJS-style WebSocket Gateways for Rasengan Server: rooms, broadcasting, and typed events on top of `app.websocket()`.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/ws
  ```

### @rasenganjs/queue

- **Description**: Background job queues for Rasengan Server: retries, delayed/recurring jobs, and dead-letter handling.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/queue
  ```

### @rasenganjs/drizzle

- **Description**: Drizzle ORM integration for Rasengan Server, via the DI container.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/drizzle drizzle-orm pg
  ```

## Deployment Packages

### @rasenganjs/serve

- **Description**: A CLI tool to serve the Rasengan.js app in production mode.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/serve
  ```

### @rasenganjs/vercel

- **Description**: A Vercel adapter for deploying Rasengan.js applications.
- **Installation**:
  ```bash title="Terminal"
  npm install @rasenganjs/vercel
  ```
